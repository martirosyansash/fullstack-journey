# Smart Todo App

A vanilla JavaScript Todo application built as part of my Full Stack Web Development journey.

## Features

- Add tasks
- Complete / uncomplete tasks
- Delete tasks
- Edit tasks
- Clear completed tasks
- Clear all tasks
- Search tasks
- Filter tasks
- Sort by priority
- Sort by deadline
- Task priorities
- Task deadlines
- Due today / overdue indicators
- LocalStorage persistence
- Responsive design
- Debounced search

## Technologies

- HTML
- CSS
- JavaScript
- DOM API
- LocalStorage
- JSON
